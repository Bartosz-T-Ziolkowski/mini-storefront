# Mini-Storefront

Mini Storefront is an interactive e-commerce web application built with Next.js, React, JavaScript, and Tailwind CSS. The application allows users to browse and filter products, manage a shopping cart, track inventory, and view dynamically calculated purchase totals. This project helped me strengthen my understanding of React-based web development, state management, and building interactive user interfaces.

In order to setup this application, copy its contents to a directory on your computer. Then, run the following commands:
1. npm install
2. npm run dev

Then, open http://localhost:3000 on your browser to view the application contents.
